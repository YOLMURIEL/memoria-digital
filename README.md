# MEMORIA — prototipo web
Esta es una maqueta funcional y estática para la candidatura a Hexagonal Innova.

Incluye:
- muro digital navegable;
- buscador y filtro por año;
- ficha modal de una persona;
- explicación del concepto;
- metodología;
- uso responsable de IA;
- red de colaboradores;
- fases de prototipado.

IMPORTANTE:
Los nombres de la maqueta son marcadores de posición. No deben sustituirse por nombres reales sin comprobar fuentes, criterios de publicación y aspectos legales/éticos.

Para probarla: abrir index.html en un navegador.
Para publicarla gratuitamente: puede subirse como sitio estático a GitHub Pages.
