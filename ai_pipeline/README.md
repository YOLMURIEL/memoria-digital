# Memoria Digital — AI Data Pipeline

This folder contains the experimental AI pipeline developed for Memoria Digital.

The purpose of the pipeline is to explore how artificial intelligence can transform public official documents into structured, validated data that can be used by the digital memorial.

## Pipeline

Public official documents  
↓  
Document parsing  
↓  
Computer vision when required  
↓  
AI-based information extraction  
↓  
Structured schema  
↓  
JSON mapping  
↓  
Deterministic validation  
↓  
Memoria Digital

## Principle

AI is used to process and structure information at scale, but it is not allowed to invent information about the women represented in the memorial.

Official sources remain the reference for factual information.

The pipeline separates:

- source information;
- AI-assisted extraction and structuring;
- deterministic validation;
- final publication.

The objective is to make the process reproducible, transparent and scalable while preserving the integrity of the original public information.

## Current status

This is an experimental development stage.

The first objective is to process one official source from end to end before extending the pipeline to additional documents and years.

## Technologies under development

- Document parsing
- Computer vision
- Generative AI / language models
- Structured schemas
- JSON
- Deterministic validation
- Open-source web development
